# MCP 服务使用指南

MCP (Model Context Protocol) 是一个开放标准，允许 AI 模型安全地访问您的本地数据和工具。本项目内置了 MCP Server，可以让你使用 AI 助手（如 Claude Desktop, Cursor, Windsurf 等）直接管理和创作故事内容。

## 获取配置

在管理后台，你可以方便地获取连接所需的配置信息。

1. 登录 Text RPG 的管理后台。
2. 在页面右上角导航栏，找到并点击 **MCP** 图标。
3. 在弹出的窗口中，你会看到适用于不同客户端的配置信息。

## 如何使用

### 1. 配置客户端

Text RPG 的 MCP 服务仅支持 Server-Sent Events (SSE) 模式。请确保你的 AI 工具支持通过 HTTP SSE 连接 MCP 服务。

在管理后台获取配置后，将其添加到你的 AI 助手配置文件中。

**配置示例**

```json
{
  "mcpServers": {
    "adventext-creator": {
      "url": "https://adventext.fun/api/mcp/sse",
      "headers": {
        "Authorization": "Bearer xxxx"
      }
    }
  }
}
```

其中 `url` 为服务器地址，`Authorization` 中的 Token 是你的访问凭证，**请勿分享！**

### 2. 开始创作

配置完成后，重启你的 AI 助手。现在你可以直接用自然语言让 AI 帮你创作游戏了！

**示例指令：**

- “帮我创建一个新的故事草稿，名叫《勇者的试炼》。”
- “在《勇者的试炼》里创建一个‘村庄广场’场景，描述是一个宁静的早晨。”
- “给‘村庄广场’添加一个选项‘去森林’，跳转到新场景‘黑暗森林’，并要求玩家必须有‘铁剑’才能进入。”
- “创建一个物品‘铁剑’，描述是‘生锈的铁剑’。”
- “查一下现在的场景有哪些选项。”

## 可用能力

目前的 MCP Server 支持以下核心功能：

*   **故事管理**：创建草稿、设置初始属性、设置初始背包、设置起始场景。
*   **场景管理**：增删改场景、更新场景内容、设置场景属性。
*   **选项系统**：创建和编辑选项，支持复杂的触发条件（属性、物品、时间等）和触发效果（获得物品、属性变更、剧情跳转）。
*   **物品与成就**：定义游戏内的物品和成就系统。
*   **完整查询**：获取故事的完整定义结构，方便 AI 理解上下文。
