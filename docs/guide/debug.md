# 如何调试

你已经编写好自己的故事了，但是想跑跑看有没有问题。有两种方式：

## 模拟运行

在场景编辑面板上方有一个按钮**模拟运行**，点击就会在右侧弹出一个侧边栏，上面就是故事的起始场景，在模拟运行窗口你可以模拟玩家游玩故事，还可以直接选择跳转到指定场景去调试。也可以直接新增编辑玩家的属性与背包。

在场景运行过程，场景面板回实时定位到对应的场景卡片，方便随时进行调整。对场景调整后，需要重新进入场景才会引用最新修改的内容。

## 草稿实跑

在你的个人首页：https://adventext.fun/u/你的用户名 。有一个**我的草稿**的页签，进入后会显示你的所有故事，可以直接点击名称直接进行游玩。看看实际运行的效果。在前面模拟运行各方面调试确认都正常后，可以在这里进行最后的确认。
