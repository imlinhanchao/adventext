# 初始背包

我们可以在玩家开始游玩时，就给他想初始发放一些物品。比如金币之类的。发放的物品需要先创建，也可以在设置界面直接创建。

点击**人物初始背包**后的 **+** 按钮，即可添加人物的初始背包物品。 

![图 0](/images/inventory/ea80901cf7228c69f1b49caf65fa07293dd608290b24b8277d01edb5b480ccd7.jpg)  

物品的创建，可以参考[物品维护](../item/maintain)章节。

在示例故事中，我们添加了一个初始物品`金币`，数量是 10。虽然没啥用，但这样会比较有 RPG 的感觉。
