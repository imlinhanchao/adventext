# 获得残剑

对于一个故事，除了一幕幕的场景，物品也是同样重要。物品可以赋予玩家更多的参与感与可玩性。

在场景 `forest` 中，有一个选项 `捡起剑`，触发这个选项会发放一个物品`生锈的剑`。在编辑器上方点击`物品管理`按钮打开物品管理对话框，这个物品我们也可以在这里找到。故事中所使用到的物品需要在这里先创建。如何创建物品可以参考文档[维护物品列表](../item/maintain)。

我们可以在选项的设置里的**效果列表**看到，这里配置了**获取物品**的效果，对象是`rusty_sword`，这个就是 `生锈的剑` 的唯一标识符。

关于**效果**配置的更多内容，可以参考文档[选项的效果](../scene/effect)。

## 追加内容

这个选项还设置了一个`追加内容`，追加内容是内容的一种动态形式，可以根据选项是否可用动态追加到场景的内容中去。

我们可以点击上方的 `模拟运行` 来看看效果。点击 `进入森林` 到达 `forest` 场景。这时的场景内容是：

> 你进入了森林，听到远处传来狼嚎声。你发现了一把生锈的剑。一些树下有些干枯的枝叶。这里以前似乎还是铁矿。

然后我们点击 `捡起剑`，场景内容变成了：

> 你进入了森林，听到远处传来狼嚎声。一些树下有些干枯的枝叶。这里以前似乎还是铁矿。

同时，`捡起剑` 选项消失。并提示**获得 生锈的剑×1.**。可以看出，追加的内容`你发现了一把生锈的剑。`在选项消失后也一并消失了。

关于**追加内容**的更多内容，可以参考[场景的选项](../scene/option#append-content)。

## 单次触发

在玩家点击 `捡起剑` 选项，千屿引擎做了三件事：

1. 添加`捡起剑`选项触发日志；
2. 发放`生锈的剑`物品到玩家的背包；
3. 切换到选项的下一个场景`forest`；

这里的触发日志是很重要的，模拟运行器也会在下发显示总日志给故事作者调试。在`捡起剑`的配置我们可以看到，选项被设置成了`单次触发`，因此选项只能被触发一次。当载入场景时，从触发日志中检查到选项已经被触发，就会隐藏该选项。

关于**选项隐藏**的更多内容，可以参考[场景的选项](../scene/option#option-hide)。
