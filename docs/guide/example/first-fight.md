# 首次战斗

> 你深入森林，遇到了一只狼。你是否要战斗？

在`forest`场景点击`继续前进`，就会进入`deep_forest`场景，在这里有两个选项：`战斗`和`逃跑`。

![图 0](/images/first-fight/d6564a6377c98abd8e7d51b50ed010e54f6a9249f3310400d3a6a837d5db499e.jpg)  

**逃跑**会返回上一个场景，我们的**下一场景**是`<back>`。这个表示玩家进入当前场景的上一个场景。在某个场景有多个来源路径时，要返回上一场景会很好用。

## 弹窗提示 {#prompt}

**战斗**设置了一个之前没有配置过的项目——**弹窗提示**。这个会在玩家触发选项时弹出一个窗口。根据配置不同，弹出窗口也不尽相同。

![图 1](/images/first-fight/7cad30b494ce495bc5153970aaefd339c683ffbe22715bc6c7109d230c7f31eb.jpg)  


这里配的是**选择物品**弹窗，`选择物品` 表示的是弹出单个背包内物品选择窗口，`选择战斗的武器：`则是弹出窗口的提示语，而`武器`则限制了可选物品的类型为**武器**（物品的类型在[物品管理](../item/maintain)可以配置）。因此，将会在玩家触发选项时，弹出一个选择物品的窗口，玩家可以选择一个类型为武器的物品来进行战斗。

![图 2](/images/first-fight/779b0b9091e1345c3989435770afbfdcefb3587265b2a513ef1ecb374c12c86c.jpg)  

关于**弹窗提示**的更多内容，可以参考[场景的选项](../scene/option#prompt)。

## 条件

在**战斗**选项我们还配置了 `条件`。

条件可以在玩家触发选项时进行逻辑判断，当不满足时返回提示，并阻止其跳转到下一场景。

这里配置了两个选项：

**物品类型**条件限制了玩家必须具有类型为 `武器` 的物品。
**物品属性**条件则配置了`{"attack":5}`，也就是玩家必须有包含属性为 `attack` 且值等于 `5` 的物品。

![图 3](/images/first-fight/2c43c807cae1339d7b370c84fc8759092abefe703c417ca10a440ce5198fdfe7.jpg)  

而由于我们前面配置了**弹窗提示**让玩家选择物品，就会把条件检查限制在了玩家所选择的物品上！

关于**条件**的更多内容，可以参考[场景的条件](../scene/condition)。

## 属性变化

在**战斗**选项我们还配置了一个 `效果`。

![图 4](/images/first-fight/a74faf53ecd95578732249926990365067dd89e6487ee64bd56eff3784322534.jpg)  

这是一个**属性变化**的效果，属性指的是玩家的属性，可以通过编辑器的 `故事设置` 配置属性的初始值。比如这里配置的 `cave` 就是在`故事设置`中配置的属性。

玩家的属性可以是内置的，也可以是公开的。所有未设置 **名称** 的属性都是内置属性。其实就相当于一个运行过程的变量。

比如这里的 `cave` 就是用于记录是否可以直接抵达山洞场景的变量，当我们打败狼后，这个变量就会被设置为 1。继而影响到 `forest` 场景的 `继续前进` 和 `前往山洞` 选项的显示隐藏。在这两个选项中的条件，配置了**属性**条件，在属性等于配置的值时才显示。通过这种方式，就可以在玩家状态变化时，跳转的场景也同步变化。
