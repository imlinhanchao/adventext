# 故事开端

> 你站在一个分岔路口，左边是黑暗的森林，右边是阳光明媚的小路。

`start` 是示例故事的起始场景。所谓起始场景，就是用户开始游玩首个进入的场景，我们可以看到场景名称旁边有个 🚩 图标。你若要设置其他场景为起始场景，把鼠标移动到场景名称上，点击灰色的 🚩 图标即可。

一个场景分为名称（也就是标识符），内容和选项。名称是不会对用户显示的，只是在编辑时作为唯一标识符使用。内容支持 Markdown，你可以使用 Markdown 语法编写场景的内容。

例如在这个场景中，内容就是 **你站在一个分岔路口，左边是黑暗的森林，右边是阳光明媚的小路。**，由此引出两个选项：`进入森林` 和 `走小路`。这两个不同的选项将会把玩家带到不同从场景去。

`进入森林` 会进入 `forest` 场景，而 `走小路` 则会进入 `sunny_path` 场景。

这样几个简单的元素，就构成了一个基础的场景。其他的场景，也是从这样的内容 + 选项中建立起来的。通过这样的设计，就可以将玩家带入由剧情编织的网，触发你所设计的精彩的故事。
