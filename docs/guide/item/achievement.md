# 成就配置

成就是游戏的全局奖励，可以在游戏中通过完成特定的任务或达到某些条件来解锁。在编辑器上方的**成就维护**可以添加游戏可以颁发的成就。

## 成就的配置

成就的配置非常简单，主要包括以下几个部分：

1. **标识符**：物品的唯一标识，用于在使用物品的设置项目中引用物品；
2. **名称**：物品的名称，用于在背包中显示与发放物品时显示；
3. **描述**：物品的描述，会作为 tip 显示在物品上；
4. **获得的条件**：成就获得的条件，满足该条件时，成就将会被解锁。配置方式类似于[选项的条件](../scene/condition)。也可以不配置条件，而在选项的效果中配置颁发。

## 展示

发布的故事在首页会显示其能获得的成就数量，而玩家在游戏中获得成就后，可以在个人中心的成就列表中查看已获得的成就。
