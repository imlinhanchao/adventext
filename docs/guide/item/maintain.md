# 维护物品列表

在编辑器的上方，有一个**管理物品**的按钮。点击即可打开物品维护窗口。

![图 0](/images/maintain/e171b4632b545f41bc9ad644b50f707d724413de708f02a50fe421352f6de567.jpg)  

## 新增物品

点击维护窗口左上方的 **+** 打开新增窗口，需要填写如下物品信息：

1. **标识符**：物品的唯一标识，用于在使用物品的设置项目中引用物品；
2. **名称**：物品的名称，用于在背包中显示与发放物品时显示；
3. **描述**：物品的描述，会作为 tip 显示在物品上；
4. **类型**：物品的类型，一般用于将物品进行归类，在某些场景下可以限制玩家使用指定分类的物品；
5. **属性**：物品的内置，这个与故事中的属性是类似的。无名称的属性相当于物品的常量，可以用于各种交互运算；

![图 1](/images/maintain/d4ac7e0429c45b4b9d4732fad43abb9d8c9979a1db3baa9027357fb9662fe768.jpg)  

你可以不必一开始就维护好所需要的物品列表，在需要的时候再添加就可以了。

## 示例

在示例故事中，最开始是一把 `生锈的剑`，可以看到其有一个属性 `攻击力` 为 1。这个攻击力在击退野狼的场景中就作为了是否击退成功的判断条件。

而在`恢复药水`药水中，更是有三个属性，其中的`生命力`和`体力`作为了使用的效果。而 `售价` 则是在玩家与商店交易过程中扣除金币计算的常量。

![图 3](/images/maintain/18a0bf5bf177411258cbbd7820a7a07685bc7cd08608a4c0b5fe92d62fa72c6d.jpg)  

其他物品的设置，大多类似。

## 批量导入

如果需要维护大量物品，可以使用批量导入的功能；下载模板填写后再导入即可。需要注意属性的填写格式为 `标识符1:值1:名称1;标识符2:值2` 的形式（名称可省略）。
